
## Prérequis 

node v20.19 ou plus
npm 11.15.0

---

## Lancer le projet avec Docker

### 1. Construire l’image Docker

Exécutez la commande suivante à la racine du projet :

```bash
docker compose up --build
```

Le projet sera ensuite accessible à l’adresse suivante :

```txt
http://localhost:5173
```
